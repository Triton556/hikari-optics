- `index.html:19`: исходный `/src/main.js` оставлен; Vite корректно преобразовал его
  в `/hikari-optics/assets/index-D1JUbv_K.js`. CSS также подключён из подпапки.
- Все файлы `src/` и `index.html` проверены на абсолютные строки, URL, `fetch`,
  загрузчики, CSS `url()`, `new URL(...)` и `import.meta`.
  Исправлять пути приложения не понадобилось. Ассеты сцены создаются программно.
- `src/refraction.js:22`: URL SCHOTT является комментарием с источником данных.
  `src/wayfinding.js:10` и `index.html:14`: адрес W3C — пространство имён SVG,
  не сетевой ресурс. Внешних CDN, Google Fonts и runtime-загрузок не найдено.
  CSS использует Manrope с системными fallback-шрифтами, без загрузки шрифта.

  build-job используют `VITE_QA=0`; в единственном JS-чанке нет `qa-panel`,
  отдельных QA-чанков нет. При открытии production с `?qa` QA-панель отсутствует.
- README: заменён Live demo, удалена оговорка о входе, добавлен деплой через
  Actions при push в `main`. Другие факты сохранены; `chatgpt.site` больше нет.
- `.github/workflows/pages.yml`: образец Lumen Relay, Node 22, npm ci/test/build,
  configure-pages v5, upload-pages-artifact v3 (`dist`), deploy-pages v4.
  `pages: write` и `id-token: write` есть только в deploy-job, concurrency `pages`.

- `npm test`: **72 passed / 0 failed**, без skipped/cancelled.

## Локальная проверка production

Playwright управлял установленным Chromium/Google Chrome 155.0.8059.84 в headless,
1440×900 и 390×844, DPR 1. Использован уже установленный Playwright из runtime,
новых зависимостей проекта и системного софта не добавлено.
Временный Node HTTP-сервер отдавал только `dist/`, смонтированный на
`http://127.0.0.1:4173/hikari-optics/`; запросы вне подпапки возвращали 404.
Это статическая раздача без SPA-fallback, не dev-сервер Vite.
Внешние браузерные запросы блокировались и записывались; попыток было 0.

HTML, CSS и JS получили HTTP 200. В двух браузерных сценариях: **0 ошибок
консоли/pageerror, 0 failed requests, 0 HTTP 404, 0 внешних запросов**.
WebGL 2.0 работал через ANGLE/NVIDIA RTX 4060 Laptop GPU, contextLost=false.
Есть предупреждение шейдерного компилятора X3595 о производных в цикле;
оно не мешало рендеру. Это не заявка на отсутствие предупреждений.
